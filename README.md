## Featured Projects

### 80/20 Outbound System
**Sales outreach CRM for managing leads, assignments, communication, and team activity.**

A multi-role CRM designed around real sales workflows, including Owner / Manager / Agent roles, lead import and assignment, multichannel outreach, real-time presence, and activity statistics.

**Stack:** Next.js · TypeScript · MongoDB · Real-time Web Applications

---

### SignSpeak
**Pakistan Sign Language recognition and translation system.**

An accessibility-focused final-year project combining a Kotlin Android application, machine-learning pipeline, backend services, and a Pakistan Sign Language dataset. The system uses landmark-based sequence recognition for real-time sign understanding.

**Stack:** Kotlin · TensorFlow Lite · Python · MediaPipe · LSTM · FastAPI · Supabase

→ [View SignSpeak](https://github.com/AbuZar-Babar/SignSpeak)

---

### TrekPal
**Multi-platform travel management ecosystem.**

A full-stack travel platform connecting travelers, agencies, hotel managers, vehicle providers, and administrators. The system uses a monorepo architecture with multiple web portals, a mobile application, a shared backend, PostgreSQL, and real-time communication.

**Stack:** React · TypeScript · Flutter · Node.js · Express · PostgreSQL · Prisma · Supabase · Socket.io

→ [View TrekPal](https://github.com/AbuZar-Babar/TrekPal)

---

### HomeEase
**Service marketplace platform for connecting households with service workers.**

A role-based platform covering customer and worker experiences alongside administrative management, with a PostgreSQL/Supabase backend and payment-service integration architecture.

**Stack:** Flutter · React/Vite · Supabase · PostgreSQL · REST APIs

→ [View HomeEase](https://github.com/AbuZar-Babar/HomeEase)
